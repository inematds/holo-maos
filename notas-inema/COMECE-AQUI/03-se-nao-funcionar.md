# SE NÃO FUNCIONAR

1. Acenda uma luz virada para você. Isso resolve mais do que qualquer ajuste no código.
2. Câmera bloqueada? Ícone de câmera na barra de endereço do Chrome → Permitir → TENTAR CÂMERA.
3. Sem webcam? Acrescente ?sim=1 no endereço: duas mãos sintéticas fazem a demonstração.
4. O mouse funciona em tudo, sempre, como alternativa.
