# O QUE RODA SEM INTERNET

Tudo. O reconhecimento das mãos é o MediaPipe do Google, e ele vem dentro da
própria pasta do projeto — não é baixado de nenhum servidor na hora de usar.

Isso significa três coisas: funciona offline, bloqueador de anúncio não quebra,
e as imagens da sua câmera não chegam em servidor nenhum.

O servidor é Python puro, 180 linhas, sem instalar nada além do Python 3.
