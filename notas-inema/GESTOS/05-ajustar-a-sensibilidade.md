# AJUSTAR PARA A SUA MÃO

No arquivo holo.html, perto do começo do script:

- PINCH_IN = .30 — o quanto os dedos precisam se aproximar para valer belisco.
  Número MAIOR = mais fácil de pegar (e mais fácil de pegar sem querer).
- PINCH_OUT = .42 — o quanto precisa afastar para soltar.
- PINCH_EARN = 2 — quantos quadros seguidos confirmam o gesto. Evita tremida.
- AMP = 1.45 — o alcance. Aumente se você precisa esticar o braço para chegar na
  borda da tela; diminua se o cursor parece nervoso.
